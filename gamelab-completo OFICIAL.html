⚙ COMO FOI FEITO

01
Canvas API — O jogo usa canvas.getContext('2d') para desenhar tudo. A cobra é um array de objetos {x, y} representando cada segmento.
02
Game Loop — requestAnimationFrame cria o loop de 60fps. O delta de tempo controla a velocidade para ser consistente em qualquer dispositivo.
03
Movimento — A cada frame, um novo segmento é adicionado na frente (unshift) na direção atual, e o último é removido (pop) — exceto quando come comida.
04
Efeito Neon — ctx.shadowBlur e ctx.shadowColor criam o brilho. A trilha usa rgba com opacidade decrescente nos segmentos.
05
Som 8-bit — Web Audio API gera tons sintéticos. OscillatorNode + GainNode criam efeitos sem nenhum arquivo de áudio.

⚙ COMO FOI FEITO

01
Matriz 2D — O tabuleiro é um array 10×20. Cada peça (tetromino) é definida como matriz de 0s e 1s. Ex: L-piece = [[1,0],[1,0],[1,1]].
02
Rotação — Rotacionar uma peça é transpor a matriz e inverter linhas: p[y][x] → p[x][rows-1-y]. Wall-kick verifica se cabe após rotacionar.
03
Gravidade — Um contador de tempo determina quando a peça cai. A cada nível, o intervalo diminui (nível 1 = 800ms, nível 10 = 80ms).
04
Clear de linhas — Quando uma linha fica completa (every(cell => cell !== 0)), é removida e o score aumenta. 4 linhas simultâneas = TETRIS!

Física da bola — A bola tem vx e vy (velocidade). Ao bater na parede, vy *= -1. Ao bater na raquete, o ângulo muda baseado no ponto de impacto.
02
Inteligência Artificial — A IA move a raquete em direção à bola com velocidade limitada, criando um desafio justo. Ela não é perfeita de propósito!
03
Efeito de rastro — A cada frame, desenhamos o fundo com fillRect semi-transparente (rgba(0,0,0,0.3)), criando um rastro que some gradualmente.

⚙ COMO FOI FEITO

01
Grid de inimigos — Os aliens são armazenados em array com posição x, y e status alive. Toda a grade move-se junta, revertendo direção ao atingir as bordas.

⚙ COMO FOI FEITO

01
CSS 3D Flip — Cada carta tem duas faces (.front e .back). A classe .flipped aplica rotateY(180deg) ao container com transform-style: preserve-3d.
02
Fisher-Yates Shuffle — Para embaralhar: percorre o array de trás para frente, trocando cada elemento com um aleatório anterior. Garante distribuição uniforme.
03
Lógica de pares — Quando 2 cartas são viradas, comparamos os data-value. Par correto = ficam visíveis. Errado = setTimeout de 800ms vira de volta.

⚙ COMO FOI FEITO

01
Parallax — O chão tem 2 camadas em velocidades diferentes. Objetos de fundo (montanhas) movem-se mais devagar que os obstáculos, criando profundidade com simples x -= speed * 0.3.
02
Física de pulo — O dinossauro tem velocityY. No pulo, vy = -15. A cada frame, vy += 0.8 (gravidade). Ao atingir o chão, vy = 0.
03
Geração procedural — Obstáculos surgem em intervalos aleatórios (Math.random()) com alturas variadas. A velocidade cresce gradualmente com o score.
